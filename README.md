# كلماتي — كلماتٌ تبقى

منصة أدبية لأقوال وخواطر أصلية بالفصحى والدارجة الجزائرية: كلمة اليوم، مكتبة، محفوظات شخصية مع ملاحظات، بطاقات مشاركة، لحظة سكون، وتطبيق ويب يعمل دون اتصال (PWA).

## البنية

| الجزء | التقنية | المكان |
|---|---|---|
| الواجهة | React 19 + Vite + Tailwind | `src/` |
| الخادم | Cloudflare Worker | `worker/index.ts` |
| قاعدة البيانات | Cloudflare D1 (يجهّزها الخادم بنفسه) | `worker/seed.ts` |
| النشر | Cloudflare Workers Builds (تلقائي عند كل رفع) | `wrangler.jsonc` |

### ما يقدّمه الخادم

- `GET /api/quotes` — الأقوال المنشورة. القول **المجدول** يظهر وحده عند حلول موعده.
- `POST /api/events` — إحصاءات حقيقية (قراءة، حفظ، مشاركة): الزائر يُحسب مرة لكل قول ونوع في اليوم، ولا يُخزَّن عنوانه.
- `/q/<الرابط>` — صفحة دائمة لكل قول، بعنوانه ووصفه لتظهر المعاينة صحيحة في واتساب وX ومحركات البحث.
- `/sitemap.xml` و`/robots.txt` — يُبنيان تلقائياً.
- `/api/admin/*` — لوحة الكاتب على `/admin`، بكلمة مرور تُحفظ سرّاً على Cloudflare فقط، مع قفل لمدة 15 دقيقة بعد 5 محاولات خاطئة.

## النشر

المستودع مربوط بـ Cloudflare Workers Builds: كل رفع إلى `main` يُنشر تلقائياً.
- الواجهة تُبنى تلقائياً (`build.command` في `wrangler.jsonc`).
- قاعدة البيانات تُنشأ تلقائياً عند أول نشر، والخادم يجهّز الجداول والأقوال الأولى بنفسه عند أول طلب.
- كلمة مرور لوحة الكاتب: في Cloudflare ← kalimati ← Settings ← Variables and Secrets، أضف سرّاً باسم `ADMIN_PASSWORD`. بدونها يبقى الموقع مفتوحاً للقراء وتبقى لوحة الكاتب مغلقة.

## التشغيل محلياً

```bash
npm install
echo 'ADMIN_PASSWORD="local-password"' > .dev.vars
npm run preview          # الموقع كاملاً مع الخادم على http://localhost:8787
```

للعمل على الواجهة فقط مع إعادة التحميل الفوري: شغّل `npm run preview` في نافذة و`npm run dev` في أخرى (طلبات `/api` تُمرَّر إلى الخادم المحلي).


## استوديو كلماتي

قسم داخل `/admin` يحميه تسجيل دخول الكاتب نفسه؛ لا يضيف حسابًا عامًا أو صلاحيات جديدة.
- توليد 5 أو 10 مسودات بالفصحى أو الدارجة الجزائرية مع النبرة والطول.
- تنقيح وبدائل واستعادة النسخة السابقة أثناء جلسة التحرير. بعد الحفظ يبقى سجل التعديلات على الخادم.
- معاينة وتصميم بطاقات الستوري والمنشور بالختم الأحمر. الاقتباس العالمي يحتفظ بالقائل والمصدر.
- مقارنة لغوية بسيطة مع نصوص المكتبة (ليست فحص سرقة أدبية أو إثبات أصالة).
- نقل المختار إلى مسودة، ثم مراجعة واعتماد/نشر/جدولة من المحرر القائم.
- مخطّط أسبوعي: فصحى أصلية، ثم إنجليزية/فرنسية موثّقة، ثم مثل بلهجة عربية. لا تُنشر مقترحات الذكاء الاصطناعي تلقائيًا ولا يجري النشر إلى شبكات التواصل.

### تشغيل التوليد

التحرير اليدوي والتصميم والجدولة تعمل دون خدمة ذكاء اصطناعي. التوليد يحتاج Workers AI باسم `AI` على الخادم؛ إذا غاب تظهر حالة «غير مفعّل» ولا تُختلق نتائج.

لإعداد الربط في مشروع Cloudflare، أضف إلى `wrangler.jsonc` بعد تفعيل الخدمة على حسابك:

```json
"ai": { "binding": "AI" }
```

أو اربط الخدمة من لوحة Cloudflare مع مراعاة إعداد النشر المستخدم. النموذج المستخدم هو `@cf/meta/llama-3.3-70b-instruct-fp8-fast`. الاستدعاءات تجري من الخادم فقط، وقد تخضع لاستهلاك/رسوم Cloudflare؛ لم يتم تفعيل الخدمة أو إجراء استدعاء مدفوع ضمن هذه التعديلات. اختبارات التوليد تستخدم مزوّدًا محاكيًا.

### الدورة اليومية

تبدأ الدورة المرجعية في 18 أكتوبر 2026: فصحى أصلية ← اقتباس عالمي ← مثل شعبي، وتتكرر كل ثلاثة أيام. `shared/daily.ts` يختار النص نفسه للصفحة والإشعار وفق التاريخ المحلي. الاقتباس المخصّص بتاريخ `featuredDate` له الأولوية، ولا يُقبل تعارض بطاقتين منشورتين/مجدولتين على اليوم نفسه من المحرر. عند غياب محتوى لنوع اليوم يجري اختيار نص متاح؛ لا نملأ الفراغ باقتباسات أو نسب مختلقة. يجب إضافة الاقتباسات العالمية ومصادرها من الإدارة قبل اكتمال الدورة.

المخطّط يعمل الساعة 13:00 بتوقيت جهاز الكاتب ويحوّل موعد النشر إلى UTC. حكمة اليوم الافتراضية تُحسب بتاريخ القارئ المحلي. النص غير المنشور قبل موعده لا يظهر مبكرًا.

### الإشعارات والسكون

- فحص الإرسال كل دقيقة بدل 15 دقيقة. قبول خدمة الدفع للطلب لا يضمن ظهوره فورًا على الجهاز.
- صفحة الإعدادات تتحقق من الاشتراك المسجّل على الخادم، وتعرض أخطاء حفظ الموعد، والإرسال التجريبي، وحالة عدم الدعم.
- الموعد الذي مضى عند الاشتراك يبدأ من الغد؛ اختيار الدقيقة الحالية يسمح بإرسالها عند الفحص التالي.
- لا يمكن اختبار التسليم الفعلي دون جهاز مشترك وأذونات النظام. التوليد والفهرسة والإشعارات على الموقع المنشور لا تصبح مفعلة بمجرد رفع فرع المراجعة.
- «جميع الحكم» في لحظة سكون يتتبّع المعرّفات المعروضة محليًا ولا يعيدها حتى انتهاء المجموعة، ثم يبدأ دورة جديدة مع منع تكرار آخر نص مباشرة. المحفوظات والكلمات القصيرة لها دورات مستقلة. «حكمة اليوم فقط» يعرض نصًا واحدًا عمدًا.

### التحقق

يتطلب الاختبار Node.js 24 أو أحدث:

```bash
npm ci
npm run lint
npm test
npm run build
```

لاختبارات الخادم المحلية فقط، شغّل Wrangler بكلمة مرور اختبار `local-test-only`، ثم:

```bash
LOCAL_TEST_URL=http://localhost:8787 npm test
```

لا تستخدم هذا العنوان أو كلمة المرور مع الموقع المنشور. تفحص اختبارات الخادم حماية الاستوديو، والمصادر، وإخفاء المسودات، وتعارض الجدولة. لا تختبر تسليم إشعارات حقيقيًا ولا تستدعي نموذجًا مدفوعًا.
