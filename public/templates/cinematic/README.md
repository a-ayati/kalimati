# القالب السينمائي — ثمانية

محرّر ثابت اختياري لمنشورات 1080 × 1350. لا يستدعي نموذجًا ولا يرفع الصور ولا ينشر المحتوى.

## الهوية المعتمدة

- خط ثمانية المرفق، بحجم 78 ثابت في جميع المنشورات؛ لا تغيير لنسب الحروف أو رسم مع `maxWidth`.
- سطران عند الخطين الأساسيين y=918 وy=1045، يتوسطان العرض x=540.
- مساواة حدود السطرين بالكشيدة عند الوصل الصحيح وبالمسافات بين الكلمات فقط.
- رسم كل كلمة كاملة بلونها؛ كلمة محورية واحدة بلون فاقع، مع النقاط والتشكيل.
- تعتيم شعاعي خفيف خلف النص وفاصل ضوئي متلاشٍ عند y=1096؛ لا إطار متقطع ولا توقيع AYATI.
- الصور والعبارات قابلة للتغيير، والتشكيل الخفيف متاح بإدخاله في النص.
- إذا لم تتسع العبارة، يُطلب اختصارها أو إعادة تقسيمها بدل ضغطها أو قصّها.

## الربط

افتح `index.html` من عنوان المستضيف نفسه. لنقل عبارة، أضف JSON مرمّزًا بواسطة `encodeURIComponent` إلى fragment الرابط (`#`). لا يرسل المتصفح fragment إلى الخادم:

```js
const payload = { text: 'ابدأ الآن بما لديك.', keyword: 'لديك', author: '', source: '' };
const href = '/templates/cinematic/index.html#' + encodeURIComponent(JSON.stringify(payload));
```

الحقول: `text`، أو `line1` و`line2`؛ `keyword`؛ `translation`؛ `author`؛ `source`؛ `sourceUrl`.
لا تُفسّر الحقول كـHTML، ولا تُجلب صور أو ملفات من روابط يمرّرها النص. اقتباسات المصادر تحتفظ بالقائل والمصدر؛ لا تُختلق ترجمة للعبارة المنقولة.

## الاستخدام

اختر صورة من الجهاز، وعدّل السطرين والكلمة المميزة واللون. اضغط «تحميل PNG». يمكن رفع الناتج إلى أدوات الوسائط القائمة في المنصة؛ هذا المحرّر لا يغيّر المنشور ولا حالة موافقته أو جدولته.

`layout.mjs` مستقل عن DOM وتختبره اختبارات المشروع. `editor.js` يستخدم Canvas الأصلي ودعم العربية في المتصفح. جميع الأصول محلية؛ لا CDN أو خدمات إضافية.
